# Taller 3 - Programación Front End

## Descripción

Aplicación de carrito de compras desarrollada con Vue.js, JavaScript y CSS.

## Objetivos

- Gestionar productos disponibles.
- Agregar productos al carrito.
- Controlar stock.
- Calcular total de compra.
- Mostrar alertas al exceder el stock disponible.

## Tecnologías

- Vue 3
- Vite
- JavaScript
- CSS
- Git
- GitHub

## Ejecución

Instalar dependencias:

```bash
npm install
```

Iniciar entorno de desarrollo:
```bash
npm run dev
```
